## 新版行为

- 产品名/窗口为“小寻云同步”，版本 0.2.0。页面不再出现测试版、技术栈说明、密码不保存等旧文案。
- macOS Keychain / Windows Credential Manager 保存账号信息。未勾选记住密码：只记服务器、账号，密码字段为空；勾选后才保存密码。自动登录需要记住密码，每次启动自动尝试一次，失败提示并允许手动重试。网页永远不能读取已保存的密码。
- 清除凭据带二次确认，不撤销已授权设备、不删除同步文件；要撤销设备仍需管理员操作。
- 增加按目录的文件索引列表、大小、时间、逐项状态、分页和筛选；同步概览包括本机待接收与服务器待接收项目（含删除），离线/错误/暂停不标成同步成功。
- 维持 app identifier `com.xun.cloud.test`、设备证书及原同步根，**不要为去掉 Test 字样搬迁/删除数据**。历史磁盘路径保留以避免重新配对或重复下载。新文件扫描后进入列表；此版本不提供上传/下载按钮或删除操作。

## Windows 接手任务（复制给 Windows 代理）

1. 在新目录解压 0.2.0 源码包，核对 SHA-256 和 MANIFEST。保留你已有修改、验证记录和旧安装包，不覆盖已有工作区。
2. 对比旧包与新包的 `source/desktop/`，重点为 `web/*`、`web_test.cjs`、`src-tauri/src/{main,account,files}.rs`、Cargo.toml/Cargo.lock 与版本配置。本轮没改同步协议和 Go 内核。
3. 按包内 `build-windows.ps1` 构建；新增 keyring 3.6.3 的 windows-native 后端，由锁文件解析，不自行用文件/base64 保存密码。不得把服务器管理 key 或密码写入证据。
4. 先正常关闭旧客户端及其专属内核，再安装/运行“小寻云同步”0.2.0。不删旧配置。identifier 不变，必须复用同一个 Device ID、testuser 空间及现有文件。
5. 勾选记住密码和下次自动登录，登录后退出重开，确认不输入密码即可连接；密码框始终为空。验证错误密码、服务器离线、凭据库失败时有明确提示且无无限重试。
6. 展开两个已验收子目录，确认文件名、大小（1 MiB）、修改时间、与服务器一致的状态。目录只显示“目录”，不以目录元数据声称全部子文件成功；离线后不能仍宣告全端同步完成。检查特殊字符文件名安全显示、上级目录、分页、筛选。
7. 清除登录信息会清理 App 自己的凭据，但不应删除文件或让既有同步停止；如需要继续自动登录，最后再勾选并保存。不要删除系统里其他凭据，不改系统证书或防火墙。
8. 回报 Windows 新版本产物、设备身份是否不变、凭据保存/重开/清除结果、文件 UI 与退出清理结果。旧版跨端验收通过不等于新版 Windows 功能已验收。

指定 deepseek-flash 子代理登记失败后，用户明确选择由当前会话完成界面；本轮没有使用其他模型替代子代理。

- Rust 单元测试、Clippy（warnings as errors）、网页行为测试通过；真实 Rust→本机 HTTPS→同步索引的根目录/子目录列表通过，非法 folder ID 与相对路径被拒绝。
- 钥匙串保存、重新加载和使用已保存密码登录在显式集成检查中通过；后续换成重新签名的 App/测试二进制触发 macOS 访问授权，重复凭据检查因等待系统授权而停止，**没有绕过授权，也不能把它写成再次通过**。
